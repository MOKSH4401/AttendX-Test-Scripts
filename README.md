
# AttendX Test Scripts

## Project Description
This repository contains sample test scripts for the
AttendX student attendance application.

## Test Scripts

### 1. test_login.py
Contains sample test cases for:
- Valid login details
- Empty username
- Empty password

### 2. test_attendance.py
Contains sample test cases for:
- Present attendance status
- Absent attendance status
- Invalid attendance status

## Technology Used
- Git
- GitHub
- Visual Studio Code
- Python unittest

## Purpose
To demonstrate version control, commit history,
remote synchronization, and collaboration using Git.

## Execution
Run the scripts with Python:

python -m unittest test_login.py
python -m unittest test_attendance.py
## Version Control Update

This repository demonstrates local commits,
remote pushes, and pulling changes from GitHub.
